# FacultyMap — backend карты факультета

Учебный backend для интерактивной 2D-карты четырёх этажей ПМ-ПУ. Публичный API отдаёт этажи и опубликованные аудитории. Администратор создаёт черновики, редактирует их и публикует после проверки геометрии. Клиентская часть пока не входит в репозиторий.

## Запуск

Требуются Docker и Docker Compose. Скопируйте `.env.example` в `.env`, замените все секреты на свои и выполните:

```bash
./scripts/deploy-local.sh
```

Скрипт запускает Compose и ждёт ответа API. Миграция выполняется отдельным контейнером до запуска API. API доступен на `http://localhost:8080/api/v1`, интерактивная документация — на `http://localhost:8080/docs`. Проверка:

```bash
curl http://localhost:8080/api/v1/floors
curl http://localhost:8080/api/v1/floors/1/rooms
```

При первом запуске список аудиторий пуст: план этажа ещё не предоставлен, поэтому выдуманных данных нет. Размеры этажей сейчас условные — 1000×1000 единиц. После получения 2D-плана они уточняются миграцией, а комнаты заносятся через административный API.

## Работа с аудиториями

```bash
curl -X POST http://localhost:8080/api/v1/admin/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"значение ADMIN_PASSWORD"}'
```

Ответ содержит токен со сроком действия один час. Передавайте `Authorization: Bearer <token>` в административные запросы.

```bash
curl -X POST http://localhost:8080/api/v1/admin/rooms \
  -H 'Authorization: Bearer <token>' \
  -H 'Content-Type: application/json' \
  -d '{"floorId":1,"number":"101","name":"Лекционная аудитория","description":"","x":10,"y":20,"width":100,"height":80}'
curl -X POST http://localhost:8080/api/v1/admin/rooms/1/publish \
  -H 'Authorization: Bearer <token>'
```

Полный контракт приведён в [docs/api.md](docs/api.md), архитектура и пользовательские пути — в [docs/architecture.md](docs/architecture.md).

## Локальная разработка

Нужны JDK 21+ и sbt. Запустите `sbt test`. Для запуска API вне Docker задайте `DB_URL`, `DB_USER`, `DB_PASSWORD`, `ADMIN_USER`, `ADMIN_PASSWORD`, `ADMIN_SIGNING_KEY`, затем выполните `sbt run`. Схему БД предварительно создаёт Flyway из `src/main/resources/db/migration`.

Для проверки полного сценария на локальной тестовой БД после запуска API выполните `python3 scripts/smoke-test.py`. Скрипт добавляет две тестовые аудитории на четвёртый этаж.
